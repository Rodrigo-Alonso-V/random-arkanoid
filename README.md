# Random Arkanoid 🕹️

Prototipo interactivo desarrollado de forma individual en **Godot Engine**. Este proyecto fue mi base fundamental para dominar la lógica del motor y el comportamiento de físicas antes de desarrollar *Panic Penguin*.

## 🎮 Jugar Ahora
Puedes probar el juego directamente en tu navegador o descargarlo para Windows en mi perfil de Itch.io:
👉 [Enlace a tu proyecto en Itch.io](https://rovex2643.itch.io/)

## 🛠️ Características Técnicas y Mecánicas
* **Físicas de Rebote:** Implementación de rebotes para determinar el ángulo de la pelota según el impacto con la paleta.
* **Detección de Colisiones:** Uso y configuración de nodos de colisión 2D precisos para gestionar las interacciones en tiempo real entre la pelota, los bloques destructibles y la paleta del jugador.
* **Interfaz de Usuario (UI):** Lógica conectada para la actualización dinámica en pantalla de la puntuación (Score) y el sistema de vidas restantes del jugador.

## 🚀 Tecnologías Utilizadas
* **Motor:** Godot Engine (v4.6.1)
* **Lenguaje:** GDScript
* **Recursos Visuales:** Integración de assets y sprites externos optimizados para entornos 2D.
* **Plataformas de destino:** Web (HTML5) y Windows
